All AgentFleet features

Every feature in one list: what it does, whether it is on by default, and the command to turn it on, off or configure it. Each row links to the matching section of the docs when there is one.

On means it is active after a normal install. Off and Opt-in mean you turn it on. Automatic means it works without a setting. On request means you run it when you need it. Restart Claude Code after you change a setting. Commands starting with / run inside Claude Code; the others run in a terminal.

Lanes and routing#

Lanes are the subagents Claude hands work to. These features decide which model each lane uses and what happens when a model fails.

Work style#

These settings change how Claude approaches your tasks. Restart Claude Code after you change one.

FeatureWhat it doesDefaultCommands
Work styleSets how readily Claude hands work to a lane. balanced uses lanes for independent parts and risky reviews. direct uses a lane only when you ask. fleet delegates by default. Work style in the docs.On

Default: balanced.

Configure agentfleet config work-style direct|balanced|fleet
Reviews, fixes and retriesClaude reviews each lane's changes itself. It sends larger findings back to the lane that wrote the code, and retries a failed lane once. This works in every style that uses lanes. Reviews, fixes and retries in the docs.Automatic

No setting.

Change No command. Pick a work style instead.
Smallest complete changeNew in 2.14.0 Claude and the implementation lanes find every place a change must reach, reuse existing code before adding any, and add nothing you did not ask for, while still finishing every part the task needs. Review lanes list code a change did not need. Smallest complete change in the docs.Automatic

No setting.

Change No command. Your project's CLAUDE.md can ask for more.
Ask firstFor large, unclear or risky tasks, Claude agrees on an approach with you before it starts. Small, clear tasks start straight away. Ask first in the docs.On
On agentfleet config ask-first on
Off agentfleet config ask-first off
Branch checkBefore Claude changes files in a git repository, it checks the branch and asks whether to continue on it, switch, or start a new one. It never switches or pulls without your answer. Branch check in the docs.On
On agentfleet config branch-check on
Off agentfleet config branch-check off
Reviewer accessSets which tools the review lanes get: full (read, Bash, Edit, Write), run (read and Bash) or read-only. Reviewers edit only in an explicit FIX MODE. Reviewer modes in the docs.On

JEV (fast-jev-compaction)A mod that replaces Claude Code's compaction summary. A fast Jev model decides which old tool calls to drop. It needs a paid TypeSafe API key and sends main-conversation text to api.typesafe.ai when it compacts. Optional mods in the docs.Opt-in

Mods#

Mods are plugins that run inside Claude Code and can draw in its interface. They need Claude Code 2.1.287 or later. They show in the terminal and the Code tab of the desktop app. token-weather and JEV are mods too; you find them under Context and compaction.

FeatureWhat it doesDefaultCommands
Mods catalogAgentFleet installs a local plugin catalog named agentfleet. It holds fleet-status, lane-guard, token-weather, session-info and brain, which are on by default, and fast-jev-compaction, which is opt-in. Mods in the docs.On

Turn all mods off at install time.

Manage /plugin
Skip AGENTFLEET_MODS=0
Or flag --no-mods
fleet-status (status band)A band above the prompt that appears only when something needs action: a restart after an update, a failing lane, a usage warning above 80%, or a new suggestion. /fleet-status prints your version, profile and settings. /fleet-tasks opens a pane of this session's lanes. fleet-status in the docs.On
Off claude plugin disable fleet-status@agentfleet
On claude plugin enable fleet-status@agentfleet
Open /fleet-status
Open /fleet-tasks
lane-guardBlocks covered git changes, GitHub writes, publishing, deployments, migrations, destructive SQL and dangerous deletions in fleet subagents. It never blocks your main conversation. Turning it off also turns off outage failover. Lane guard in the docs.On
Off claude plugin disable lane-guard@agentfleet
On claude plugin enable lane-guard@agentfleet
/brainOpens a scrollable pane with agent-brain token usage, this week's estimated cost, and your project's memories when memory is on. brain in the docs.On

On since 2.7.0.

Open /brain
Off claude plugin disable brain@agentfleet
Ask agentfleet configure

Usage, cost and reports#

FeatureWhat it doesDefaultCommands
Usage reportSummarizes recent lane runs and main-conversation tokens per model. For each lane it shows runs, outcomes, errors, forbidden commands and tokens. Usage and estimated cost in the docs.Automatic

Gateway usageOn a gateway profile, AgentFleet reads the spend and limits your gateway reports for your key (OmniRoute, OpenRouter or LiteLLM). The report, /brain and the status band show them. Reported by your gateway in the docs.On

Gateway profiles only.

On agentfleet config provider-usage on
Off agentfleet config provider-usage off

agent-brain#

agent-brain is a free tool that records the tokens and cost of each Claude Code session and can keep project memory on your machine. AgentFleet installs and connects it. It never asks you to sign in. See the agent-brain site for its own documentation.

FeatureWhat it doesDefaultCommands
agent-brain usage trackingInstalls agent-brain from a checksum-verified release and connects it to Claude Code. With automatic updates on, AgentFleet also keeps it up to date. agent-brain in the docs.Opt-in

The wizard offers it; the default answer is yes.

On agentfleet config agent-brain on
Off agentfleet config agent-brain off
agent-brain memoryClaude saves decisions and project context on your machine and reads them back in later sessions. Nothing leaves the machine. agent-brain in the docs.Off

Until you say yes.

On agentfleet config agent-brain-memory on
Off agentfleet config agent-brain-memory off
Memory export and importMoves a project's memories to another machine or to a colleague. Export writes a file. Import shows a summary and asks before it writes, and skips entries you already have. Memory export and import on the agent-brain site.On request

Needs agent-brain.

Export agent-brain memory export --format json --out FILE
Import agent-brain memory import FILE
Preview agent-brain memory import FILE --dry-run
Memory V2 upgradeNew in 2.12.0 AgentFleet upgrades agent-brain's memory to the current storage format, Memory V2, after it makes a backup copy. It never upgrades a shared PostgreSQL memory store automatically. Memory storage on the agent-brain site.Automatic

On install, update and agentfleet doctor.

Run now agentfleet doctor
Preview agent-brain memory upgrade-v2

Suggestions#

AgentFleet scans a project on your machine and suggests plugins, mods, hooks and tools that fit it. It installs only what you pick.

FeatureWhat it doesDefaultCommands
/fleet-suggestScans the project locally, makes no network requests and never reads .env values. It explains what each suggestion can access before it installs anything. Suggestions in the docs.On request

The status band shows one new suggestion at a time.

Run /fleet-suggest
From a shell agentfleet suggest
Dismiss agentfleet suggest --dismiss ID
Usage learningCounts command names, tools, documentation sites and slash commands for each project, never prompt text, to improve suggestions. Suggestions in the docs.On

On for new installs.

On agentfleet config learn on
Off agentfleet config learn off
Delete data agentfleet suggest --forget
